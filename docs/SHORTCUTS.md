# Keyboard shortcuts

| Key | Action |
| --- | --- |
| Left | Previous move |
| Right | Next move |
| Home | Starting position |
| End | Last move in the current line |
| Ctrl+Left | Previous game |
| Ctrl+Right | Next game |
| Space | Play / pause (outside Guess the Move) |
| F | Flip board |
| Ctrl+O | Open PGN |
| Ctrl+G | Toggle Guess the Move |

Playback shortcuts are ignored while typing into a text entry or adjusting an
editable control. Click any notation move to jump to its position. Use the
mainline control to leave a variation. The game list can be collapsed and pane
dividers can be dragged to resize the board and notation areas.

Manual navigation pauses autoplay. Guess the Move stays active across games,
positions and PGN files until you click its button again or press Ctrl+G.
